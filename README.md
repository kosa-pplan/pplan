## 프로젝트 개요

### 프로젝트 주제
1인 가구 및 P형 성향의 여행자들을 위한 서울 여행 랜덤 여행 플래너

## 프로젝틍 인원(총 5명, 풀스택)
| **팀원**      | **역할**                                     |
|---------------|----------------------------------------------|
| **⭐️박주희**    |  팀장, 부루마블을 통한 게임 구현       |
| **🙋‍♂️김경민**    |  백엔드,프론트 프로젝트 구성, Vue 라우터 구성, 여행 리뷰 게시판 및 공유    |
| **🙆‍♂️김동혁**    |  DataBase 설계 총 책임, 회원 정보               |
| **🙋‍♀️이푸름**    |  부루마블을 통한 게임 구현                         |
| **💁‍♂️조성현**    |  카카오 API를 통한 경로 구현                       |

### 기획 배경
- **최근 여행 트렌드**
    - 자유 여행과 개별 맞춤형 여행에 대한 수요가 증가
- **필요성**
    - 현대인의 바쁜 일상 속에서 효율적으로 여행 일정을 계획하고 관리할 수 있는 도구의 필요성 증가
    - 서울의 다양한 카테고리(맛집, 카페, 놀거리)에 따른 랜덤 경로 추천을 통해 깊이 있는 여행 경험을 제공
- **타겟층**
    - MBTI가 ___P인 사람들
    - 서울 여행을 계획 중인 사람들
    - 계획을 짤 시간이 없는 사람들
    - 서울에 거주하지만 서울 여행 경험이 없는 외국인들

### 차별성
- **지역 특화 및 세분화**
    - 서울의 다양한 구역에 특화된 여행 코스 제공, 지역 특색을 반영한 여행 경험
- **게임 요소 도입**
    - 돌림판, 주사위 등 게임 요소를 도입하여 재미있고 흥미로운 여행 계획을 제공
- **랜덤 장소 추천**
    - 랜덤으로 여행지를 추천하여 계획이 부족한 P형 사용자들에게 매력적인 요소 제공

### 기대효과

- **수익 확대**
    - 제휴 및 협업을 통해 수익을 확대하고 다양한 비즈니스 모델 개발
- **지역 경제 활성화**
    - 비관심지역 관광객 유입으로 지역 경제 활성화
- **여행 트렌드 선도 및 문화 확산**
    - 새로운 여행 트렌드를 선도하며 자유로운 여행 문화를 확산


## 프로젝트 목표
- **SPA(Single Page Application) 구현**
    - 단일 페이지에서 동적 콘텐츠 로딩으로 부드러운 사용자 경험 제공
- **프론트엔드 기술 숙련**
    - Vue.js 기반의 컴포넌트 설계, 라우팅 학습 및 적용
- **백엔드 기술 활용**
    - RESTful API 설계, 데이터베이스 연동, 사용자 인증/권한 관리 구현
- **프론트엔드와 백엔드의 통합**
    - API를 통한 데이터 통신, 비동기 통신 및 보안 강화(JWT 이용)
- **실무 능력 배양 및 협업 경험**
    - Git을 통한 버전 관리, 코드 리뷰 및 데일리 스크럼을 통한 협업
